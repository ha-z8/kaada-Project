# KAADA Study | منصة الدراسة التفاعلية

منصة عربية لقراءة المواد العلمية باللغة الإنجليزية، وترجمتها أكاديميًا، ومراجعتها عبر ثلاثة مسارات صوتية.

## الوظائف الحالية
- مكتبة مواد ودروس وفقرات متعددة، مع اكتشاف عناوين الفصول من الملفات.
- استيراد PDF وDOCX وTXT ومعاينة النص وتصحيحه قبل الحفظ.
- قراءة إنجليزية، وعربية، أو مزدوجة فقرةً فقرة.
- تشغيل الصوت بالعربية والإنجليزية أو بشكل مدمج عبر أصوات المتصفح، وإضافة تسجيلات مستقلة.
- حفظ التقدم وسرعة الاستماع على حساب الطالب.
- واجهة عربية متجاوبة تدعم الوضعين الفاتح والداكن.
- Supabase Auth + private Storage + PostgreSQL RLS لكل مستخدم.
- توليد مسودة ترجمة وشرح بالعربية والإنجليزية من وظيفة Netlify محمية بتسجيل الدخول، مع التحرير اليدوي قبل الحفظ.
- الاستماع للشرح المحفوظ بالعربية أو الإنجليزية أو بالطريقتين عبر أصوات الجهاز.

## الموقع الحالي

**[KAADA Pro — https://kaada-pro.netlify.app](https://kaada-pro.netlify.app/)**

الاستضافة على Netlify مربوطة بفرع `main` من هذا المستودع، وقاعدة البيانات المستقلة هي مشروع Supabase `kaada Project` (`oaihjgmmoxvunuxtucin`). تم إعداد الجداول وسياسات عزل بيانات المستخدمين ومساحات التخزين الخاصة. يستخدم المشروع مفتاح Supabase العام من `src/lib/publicSupabaseConfig.js`، ولا يحتوي على أي مفتاح خادم سري.

**تنبيه:** تشغيل الذكاء الاصطناعي تلقائيًا يتطلب تفعيل Netlify AI Gateway على خطة مؤهلة أو ضبط `OPENAI_API_KEY` في وظائف Netlify من لوحة الاستضافة. لا تضع المفتاح في GitHub أو متغيرات `VITE_`.

## التشغيل
```bash
npm install
npm run dev
```

للبناء: `npm run build`. للاختبارات: `npm test`.

اقرأ [دليل التهيئة](docs/SETUP.md) قبل ربط قاعدة البيانات أو استضافة الموقع.

> هذا المستودع عام ولا يحتوي على ملفات مناهج مقيّدة أو بيانات تسجيل دخول. في حال كانت المادة تحمل قيود تداول، التزم بتصريح الجهة المالكة قبل رفعها إلى خدمات خارجية.

## حالة المشروع
الواجهة منشورة على Netlify، وقاعدة Supabase مهيأة، ومراجعة الشرح والصوت والتعديلات اليدوية موجودة في الكود. يحتاج تشغيل التوليد بالذكاء الاصطناعي إلى إعداد مزوّد خارجي، ويتطلب اختبارًا بحساب مستخدم فعلي للتأكد من دورة الاستخدام الكاملة.
