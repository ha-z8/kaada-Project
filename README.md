# KAADA Study | منصة الدراسة التفاعلية

منصة عربية لقراءة المواد العلمية باللغة الإنجليزية، وترجمتها أكاديميًا، ومراجعتها عبر ثلاثة مسارات صوتية.

## تسجيل الدخول والحسابات
- إنشاء حساب ذاتيًا باسم مستخدم وكلمة مرور **دون بريد إلكتروني**، مع حساب جديد بصلاحية مستخدم افتراضيًا.
- المشرف يملك صفحة **إدارة الحسابات** لإضافة المستخدمين والمشرفين وتعديل اسم المستخدم والاسم الظاهر والصلاحية، وإعادة تعيين كلمة المرور أو حذف الحساب.
- لا يمكن رؤية كلمة المرور القديمة؛ المستخدم يستطيع تعديل كلمة مروره من صفحة **حسابي**.
- **أول مشرف** يُعيّنه مالك قاعدة البيانات بعد إنشاء حسابه والتحقق منه. لا تُمنح الصلاحية تلقائيًا لأول مسجل.
- عمليات إدارة الهوية تتم عبر Supabase Edge Function `account-control`، ولا يوجد أي مفتاح سري في الواجهة.

## الوظائف الحالية
- مكتبة مواد ودروس وفقرات متعددة، مع اكتشاف عناوين الفصول من الملفات.
- استيراد PDF وDOCX وTXT وMarkdown، إضافة النص يدويًا، ومعاينة الفصول والفقرات قبل الحفظ.
- قراءة إنجليزية، وعربية، أو مزدوجة فقرةً فقرة.
- مشغّل دراسي بأربع خطوات: **قراءة أو شرح → اللغة → صوت كل لغة → تشغيل**. الوضع المزدوج يقرأ كل فقرة بالإنجليزية ثم العربية وينتقل تلقائيًا للفقرة التالية، أو يتوقف عند فقدان ترجمتها.
- ما يصل إلى **3 أصوات رجالية و3 أصوات نسائية لكل لغة** بحسب أصوات النظام المثبتة والمصنّفة بأسماء معروفة؛ تظهر الخيارات غير المتوفرة معطّلة، ويُعرض صوت جهاز غير مصنف عند توفره. لا نستنتج جنس صوت مجهول، ولا تُنشأ أصوات وهمية.
- أُزيل خيار الأصوات الواقعية المدفوعة من واجهة المشغّل؛ القراءة والشرح الصوتيان يعتمدان على أصوات المتصفح/الجهاز. تبقى آلية رفع التسجيلات المستقلة متاحة للمشرف.
- حفظ التقدم وسرعة الاستماع على حساب الطالب.
- واجهة عربية متجاوبة تدعم الوضعين الفاتح والداكن.
- صلاحيتان: **مشرف** لإدارة المواد ورفعها وتعديل الشرح، و**مستخدم** للعرض والمذاكرة والاستماع فقط. مواد مشتركة مع تقدم شخصي لكل طالب، بصلاحيات Supabase RLS.
- **ترجمة عربية علمية تلقائية بعد استيراد المواد** بموافقة المشرف مرة واحدة عند الحفظ، دون الضغط على التوليد لكل فقرة، مع فصل مسار الترجمة عن إنشاء الشرح.
- ترجمة تمر بمرحلتين (الترجمة ثم تدقيقها مقابل المصدر) مع قاموس مصطلحات بحوث العمليات والتحقق من الأرقام والعلامات الرياضية، وتبقى مسودة قابلة للاعتماد البشري.
- **ترجمة الدرس كاملًا** للمواد المستوردة سابقًا، أو تحسين ترجمة فقرة بعينها مع معاينة قبل استبدالها. يحافظ النظام على الترجمات المعتمدة يدويًا.
- توليد الشرح العربي والإنجليزي مستقل عن ترجمة النص، ولا يستبدل الترجمة الدقيقة بنص شرح تقريبي.
- الاستماع للشرح المحفوظ بالعربية أو الإنجليزية أو بالطريقتين عبر أصوات الجهاز.

## الموقع الحالي

**[KAADA Pro — https://kaada-pro.netlify.app](https://kaada-pro.netlify.app/)**

الاستضافة على Netlify مربوطة بفرع `main` من هذا المستودع، وقاعدة البيانات المستقلة هي مشروع Supabase `kaada Project` (`oaihjgmmoxvunuxtucin`). تم إعداد الجداول والمواد المشتركة وسياسات صلاحيات المشرف/المستخدم ومساحات التخزين الخاصة. يستخدم المشروع مفتاح Supabase العام من `src/lib/publicSupabaseConfig.js`، ولا يحتوي على أي مفتاح خادم سري.

**الشرح الذكي مُفعّل عبر Cloudflare Workers AI** المرتبط بحساب المشروع، ويعمل من واجهة Netlify دون إضافة مفتاح OpenAI. الترجمة والشرح بالعربية والإنجليزية يُنشآن بعد موافقة المشرف على المعالجة الخارجية، ثم يبقيهما النظام قابلين للمراجعة والتعديل. يوجد حد استخدام مجاني يومي لدى Cloudflare، ولا تتوفر خدمة غير محدودة. **مشغل الدراسة لا يعرض خدمة أصوات واقعية خارجية**؛ الاستماع يستخدم أصوات الجهاز دون مفتاح أو دفع لخدمة نطق.

## التشغيل
```bash
npm install
npm run dev
```

للبناء: `npm run build`. للاختبارات: `npm test`.

اقرأ [دليل التهيئة](docs/SETUP.md) قبل ربط قاعدة البيانات أو استضافة الموقع.

> هذا المستودع عام ولا يحتوي على ملفات مناهج مقيّدة أو بيانات تسجيل دخول. في حال كانت المادة تحمل قيود تداول، التزم بتصريح الجهة المالكة قبل رفعها إلى خدمات خارجية.

## حالة المشروع
الواجهة منشورة على Netlify وقاعدة Supabase محمية بالأدوار. **خدمة توليد الشرح النصي مفعّلة ومجربة باستخدام نص علمي افتراضي**، مع اختبار حي يؤكد جاهزية الوظيفة ومنع الدخول غير المصرح به. إنشاء الشرح يتطلب حساب مشرف وموافقة على إرسال المحتوى، ويمكن مراجعة المسودة وتعديلها. **اختبار ملف دراسي حقيقي من حساب المشرف داخل الموقع لم يُنفّذ** لأنه يتطلب جلسة مستخدم فعلية وتصريح معالجة المصدر. نظام أصوات الجهاز مستقل عن خدمة الذكاء الاصطناعي.
