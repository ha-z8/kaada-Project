# HSA 4 Study | منصة الدراسة التفاعلية

منصة عربية لقراءة المواد العلمية باللغة الإنجليزية، وترجمتها أكاديميًا، ومراجعتها عبر ثلاثة مسارات صوتية.

## تسجيل الدخول والحسابات
- إنشاء حساب ذاتيًا باسم مستخدم وكلمة مرور **دون بريد إلكتروني**، مع حساب جديد بصلاحية مستخدم افتراضيًا.
- المشرف يملك صفحة **إدارة الحسابات** لإضافة المستخدمين والمشرفين وتعديل اسم المستخدم والاسم الظاهر والصلاحية، وإعادة تعيين كلمة المرور أو حذف الحساب.
- لا يمكن رؤية كلمة المرور القديمة؛ المستخدم يستطيع تعديل كلمة مروره من صفحة **حسابي**.
- **أول مشرف** يُعيّنه مالك قاعدة البيانات بعد إنشاء حسابه والتحقق منه. لا تُمنح الصلاحية تلقائيًا لأول مسجل.
- عمليات إدارة الهوية تتم عبر Supabase Edge Function `account-control`، ولا يوجد أي مفتاح سري في الواجهة.

## الوظائف الحالية
- مكتبة مواد ودروس وفقرات متعددة، مع اكتشاف عناوين الفصول من الملفات.
- استيراد PDF وDOCX وTXT وMarkdown، إضافة النص يدويًا، ومعاينة الفصول والفقرات قبل الحفظ.
- قراءة إنجليزية، وعربية، أو مزدوجة فقرةً فقرة.
- مشغّل دراسي بأربع خطوات: **قراءة أو شرح → اللغة → صوت كل لغة → تشغيل**. الوضع المزدوج يقرأ **مقطعًا قصيرًا من سطر إلى سطرين من متن PDF** بالإنجليزية، ثم ترجمته العربية المقابلة، وبعدها المقطع التالي. تحفظ عناوين الفصل مع بداية أول مقطع.
- الاستيراد الجديد يقسم نصوص PDF/Word إلى مقاطع قصيرة محافظة على كل الكلمات والأرقام والرموز الرياضية. وتُنشأ ترجمة عربية مستقلة لكل مقطع، مع استخدام المقطع السابق واللاحق سياقًا للفهم فقط.
- الدروس القديمة: زر **«تجهيز المقاطع القصيرة»** ينشئ نسخة منفصلة قابلة للمراجعة والترجمة التلقائية بموافقة المشرف، دون حذف الدرس الأصلي أو الكتابة فوق ترجماته.
- واجهة صوتية حديثة وقابلة للطي: **نوع الاستماع، لغة القراءة، الأصوات، إعدادات التشغيل، ومقاطع الدرس**. زر رئيسي للتشغيل والإيقاف المؤقت، السابق والتالي، الإيقاف الكامل، سرعة ونسبة مستوى الصوت، معاينة الأصوات، الانتقال التلقائي ومؤشر اللغة الحالية.
- أسماء سعودية مبسطة للأصوات العربية (الرجال: **فهد، سعود، راشد**؛ النساء: **نورة، ريم، سارة**) وأسماء أمريكية للإنجليزية (الرجال: **James, Liam, Noah**؛ النساء: **Emma, Olivia, Sophia**). الأسماء الاثنا عشر ثابتة في الكود، ويُحفظ الربط الأول لكل اسم بصوته الأصلي في تخزين الموقع لهذا المتصفح؛ تغيير ترتيب أصوات النظام لا يغيّر هوية الصوت. الخانات غير المتوفرة تُعطّل ولا تنطق صوتًا بديلًا. الأصوات المصنفة بأنها Natural/Neural تُقدَّم في الترتيب عند توفرها؛ صوت Saba القديم المستبعد لا يظهر. زر «تجربة الصوت» يُسمِع عينة قصيرة قبل الاختيار.
- جودة النطق تتوقف على إمكانات نظام التشغيل والمتصفح والأصوات المثبتة. **إعادة التسمية أو تغيير ترتيب الأصوات لا تحول صوتًا قديمًا إلى صوت بشري طبيعي**؛ يتطلب الوصول إلى جودة استوديو محركًا إضافيًا قد يستلزم رسومًا. لم نفعّل مزودًا مدفوعًا أو ننقل المواد إليه تلقائيًا.
- ما يصل إلى **3 أصوات رجالية و3 أصوات نسائية لكل لغة** بحسب الأصوات المثبتة والمصنّفة بأسماء معروفة؛ تظهر الخيارات غير المتوفرة معطّلة. **أُزيل اختيار «صوت الجهاز» غير المصنّف بالكامل** من قائمة المستخدم، ولا نعرض أصواتًا وهمية أو نخمن جنس الأصوات غير المعروفة.
- أُزيل خيار الأصوات الواقعية المدفوعة من واجهة المشغّل؛ القراءة والشرح الصوتيان يعتمدان على أصوات المتصفح/الجهاز. تبقى آلية رفع التسجيلات المستقلة متاحة للمشرف.
- حفظ التقدم وسرعة الاستماع على حساب الطالب.
- واجهة عربية متجاوبة تدعم الوضعين الفاتح والداكن.
- صلاحيتان: **مشرف** لإدارة المواد ورفعها وتعديل الشرح، و**مستخدم** للعرض والمذاكرة والاستماع فقط. مواد مشتركة مع تقدم شخصي لكل طالب، بصلاحيات Supabase RLS.
- **ترجمة عربية علمية تلقائية بعد استيراد المواد** بموافقة المشرف مرة واحدة عند الحفظ، دون الضغط على التوليد لكل فقرة، مع فصل مسار الترجمة عن إنشاء الشرح.
- ترجمة تمر بمرحلتين (الترجمة ثم تدقيقها مقابل المصدر) مع قاموس مصطلحات بحوث العمليات والتحقق من الأرقام والعلامات الرياضية، وتبقى مسودة قابلة للاعتماد البشري.
- **ترجمة الدرس كاملًا** للمواد المستوردة سابقًا، أو تحسين ترجمة فقرة بعينها مع معاينة قبل استبدالها. يحافظ النظام على الترجمات المعتمدة يدويًا.
- توليد الشرح العربي والإنجليزي مستقل عن ترجمة النص، ولا يستبدل الترجمة الدقيقة بنص شرح تقريبي.
- الاستماع للشرح المحفوظ بالعربية أو الإنجليزية أو بالطريقتين عبر أصوات الجهاز.

## الموقع الحالي

**[HSA 4 Study — https://kaada-pro.netlify.app](https://kaada-pro.netlify.app/)**

الاستضافة على Netlify مربوطة بفرع `main` من هذا المستودع، وقاعدة البيانات المستقلة هي مشروع Supabase `kaada Project` (`oaihjgmmoxvunuxtucin`). تم إعداد الجداول والمواد المشتركة وسياسات صلاحيات المشرف/المستخدم ومساحات التخزين الخاصة. يستخدم المشروع مفتاح Supabase العام من `src/lib/publicSupabaseConfig.js`، ولا يحتوي على أي مفتاح خادم سري.

**الشرح الذكي مُفعّل عبر Cloudflare Workers AI** المرتبط بحساب المشروع، ويعمل من واجهة Netlify دون إضافة مفتاح OpenAI. الترجمة والشرح بالعربية والإنجليزية يُنشآن بعد موافقة المشرف على المعالجة الخارجية، ثم يبقيهما النظام قابلين للمراجعة والتعديل. يوجد حد استخدام مجاني يومي لدى Cloudflare، ولا تتوفر خدمة غير محدودة. **مشغل الدراسة لا يعرض خدمة أصوات واقعية خارجية**؛ الاستماع يستخدم أصوات الجهاز دون مفتاح أو دفع لخدمة نطق.

## التشغيل
```bash
npm install
npm run dev
```

للبناء: `npm run build`. للاختبارات: `npm test`.

اقرأ [دليل التهيئة](docs/SETUP.md) قبل ربط قاعدة البيانات أو استضافة الموقع.

> هذا المستودع عام ولا يحتوي على ملفات مناهج مقيّدة أو بيانات تسجيل دخول. في حال كانت المادة تحمل قيود تداول، التزم بتصريح الجهة المالكة قبل رفعها إلى خدمات خارجية.

## حالة المشروع
الواجهة منشورة على Netlify وقاعدة Supabase محمية بالأدوار. **خدمة توليد الشرح النصي مفعّلة ومجربة باستخدام نص علمي افتراضي**، مع اختبار حي يؤكد جاهزية الوظيفة ومنع الدخول غير المصرح به. إنشاء الشرح يتطلب حساب مشرف وموافقة على إرسال المحتوى، ويمكن مراجعة المسودة وتعديلها. **اختبار ملف دراسي حقيقي من حساب المشرف داخل الموقع لم يُنفّذ** لأنه يتطلب جلسة مستخدم فعلية وتصريح معالجة المصدر. نظام أصوات الجهاز مستقل عن خدمة الذكاء الاصطناعي.

### ثبات الأصوات واختبارها
- أسماء الأصوات الستة العربية والستة الإنجليزية مثبتة في `VOICE_NAMES` ولا تتغير تلقائيًا، وتخزن المنصة الربط بين الاسم والصوت الفعلي (الاسم واللغة) في `kaada-fixed-voice-catalog-v1` داخل بيانات هذا الموقع في المتصفح. اختيار الصوت المفضل محفوظ كذلك.
- عند حذف صوت مثبت أو تغيّر حزمة أصوات النظام، يصبح الاسم المرتبط به **غير متاح** بدل تبديله تلقائيًا بصوت آخر. تعود نفس المطابقة إذا عاد الصوت الأصلي. التثبيت محلي لكل متصفح؛ حذف بيانات الموقع أو استعمال جهاز آخر لا ينقل معه أصوات نظام التشغيل.
- وحدة الاختبارات `tests/fixedVoiceCatalog.test.mjs` تتأكد من ثبات جميع الأسماء الاثني عشر، وثباتها بعد ترتيب جديد وإضافة صوت، واختفاء الصوت ثم عودته، ومن استخدام الصوت المحدد بالاسم فعلًا أثناء النطق المحاكى.
- **الاختبار الآلي لا يثبت جودة الصوت الحقيقي على كل جهاز.** أنظمة Windows وmacOS والمتصفحات تختلف في توفر الأصوات ودعمها. عند غياب الصوت يظهر خيار غير متاح أو تنبيه، ويجب استخدام «تجربة الصوت» لسماع النطق الفعلي على الجهاز قبل اختياره.

## HSA 4 Study — هوية المنصة

- الهوية الرسمية للواجهة: **HSA 4 Study**. الشعار المعتمد هو حروف HSA نفسها على هيئة كتاب مفتوح، مع عبارة `4 Study` بخط صغير أسفلها.
- أصول التصميم: `public/hsa-logo.svg` لعرض الشعار في الصفحة الجانبية وشاشة تسجيل الدخول، و`public/favicon.svg` للأيقونة، و`public/manifest.webmanifest` لهوية تثبيت الموقع. الألوان: الأخضر الداكن `#11381D`، الأخضر الفاتح `#C2DBC9`، الذهبي البرونزي `#B08551`، والأخضر `#00804A`.
- رابط الموقع وقاعدة Supabase ومفاتيح التخزين ومعرّفات المشروع الداخلية لا تتغير مع تحديث العلامة التجارية، حتى لا تتأثر حسابات المستخدمين أو الدروس أو البيانات السابقة.
